YouTube API Services

Mobile app use and reviewer access

This page states the exact platform boundary of MoolSocial's current YouTube API use and how an authorized reviewer can inspect it.

PlatformsCurrent useNot usedReview accessControls

1. Platform status

  • Website: No. The MoolSocial public website provides company, policy and support information. It does not call or use YouTube API Services.
  • Android mobile application: Yes. YouTube API Services are integrated only in the private pre-launch Android review candidate described below.
  • iOS mobile application: No. There is no current iOS YouTube API client included in this compliance review.

2. Current Android use

The Android review client uses the Google Cloud project moolsocial-dev-503018 and package com.moolsocial.app. Its bounded declared use is limited to:

  • eligible public-video and Shorts discovery through videos.list, channels.list and bounded search.list requests;
  • YouTube metadata displayed in MoolSocial's native mobile cards;
  • playback through the official embedded YouTube player with YouTube branding, controls, advertising and the Watch on YouTube route available; and
  • a separate, user-initiated owner-channel connection using only the youtube.readonly scope after Google authorization.

3. Capabilities not active in the reviewed client

The reviewed client does not provide YouTube upload, Like, Comment, Subscribe, playlist, channel or asset mutations. It does not provide YouTube Analytics, Reporting, Live, partner, membership, Super Chat or Content Owner capability. Broader future ideas are not part of this current API client.

4. Secure Android review access

The Android application is in private pre-launch review and is not publicly listed in Google Play. Access is provided only through Google Play Internal Testing to an eligible reviewer account. The same-thread reviewer package will contain the exact tester link and release identity after the final Play-installed candidate passes device qualification.

  • Distribution: Google Play Internal Testing (private)
  • Android package: com.moolsocial.app
  • Tester link and release identity: supplied after final Play-installed device qualification

An authorized reviewer can email hello@moolsocial.com to identify the accepted secure-access method and reviewer account.
