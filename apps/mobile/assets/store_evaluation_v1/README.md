# Store-entry evaluation assets v1

These eight images are generated generic evaluation packshots, not photographs
of verified branded goods, shop inventory, or production-approved media.
Each image says TEST SAMPLE. Commercial values below are test inputs only.
Do not insert them automatically into Store stock or promote test transactions.

The table is an optional manual evaluation input set, not preloaded inventory.
The automated eight-product journey cases use purchase price 28, selling price
32 and quantity 8 consistently; they verify persistence and photo identity, not
the commercial accuracy of these example prices.

Oil, atta and salt reuse the preserved 21 September imagegen evaluation outputs;
they must not be labelled Fortune, Aashirvaad or Tata. The other five were created
24 September using the built-in imagegen tool, one image per product.

Prompt set for each new image: product-mockup, ONE square photorealistic studio
product photograph, front-facing whole pack, crisp realistic material, pure white
background, tight useful framing without clipping, no props or borders; label the
exact generic product name, pack and TEST SAMPLE; no real brand, certification or
barcode. Subjects: transparent rice pouch with cream label; green tea carton;
transparent sugar pouch; transparent red-lentil pouch; wrapped soap bar.

Images were visually inspected for subject, full-pack framing and sample label.
Images alone are not journey evidence. Required proof is actual entry/save,
saved Stock, restart, POS selection and Review Bill with unchanged SKU metadata
and photo identity. Backend, publication and device acceptance remain separate.
