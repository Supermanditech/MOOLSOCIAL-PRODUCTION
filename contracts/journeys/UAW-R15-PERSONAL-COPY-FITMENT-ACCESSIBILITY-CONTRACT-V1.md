# UAW-R15 Personal copy fitment accessibility contract V1

The exact reference matrix is 320x568, 360x640, 360x720, 375x667, 390x844,
412x915 and 430x932 at 100% and 140% text. The 14 rows are independent gates.

Each row covers Personal Mool, Eat, Ride, Book and Work roots; loading, held,
disabled, stale, offline and denied projection panels; and the six R12 legacy-
route recovery reasons. All declared copy must remain present without overflow
or max-line truncation. Every exposed action must have an accessible name, a
minimum 44x44 logical-pixel target and a working callback. The 140% rows also
exercise reduced-motion and safe-area behavior.

These surfaces contain no text input, so keyboard/IME qualification is not
applicable to R15 and is not claimed. Device accessibility remains a later
machine-gated qualification step.
