# UAW-R12 Personal legacy-route containment contract V1

1. Any old Tiffin route/link opens one truthful containment recovery state.
2. Any old Get It Done route/link opens the same shared recovery owner with
   Get It Done-specific copy.
3. Standalone Pay home/recharge/bills/scan/requests/receipts routes open Pay-
   specific recovery and never a launcher payment promise.
4. Exact transaction-owned request-confirmation and payment receipt/status/
   outcome paths remain owned by the existing Pay vertical and display their
   own unavailable state when the record is absent.
5. The obsolete generic Delivery opportunity ID is contained; exact funded
   opportunity IDs remain routed by the Work owner.
6. Old Onboard and Verify aliases are contained. Valid internal setup uses
   `/app/work/workspace/choose` and `/app/work/workspace/proof`.
7. Recovery names the unavailable intent and offers one action to the current
   owning root plus Mool. It does not silently substitute another action.
8. Search, notification, direct/deep link and legacy query aliases pass through
   the same pure route policy after authentication.

The shared recovery owner changes no vertical session or backend state. Legacy
component tests may opt into `legacyPresentationForTestsOnly`; product builds
cannot enable that default.
