# MoolSocial embedded family navigation v1

Status: founder-approved HTML navigation reference, 10 August 2026.

This immutable package freezes only three approved navigation decisions:

1. the connected vertical glass Mool family switcher;
2. the transparent compact bottom family/action language; and
3. replacement of the previous personal Flutter navigation presentation across
   Social, Shop, Food, Travel, Care and Work.

The included HTML is reference evidence and is never loaded by Flutter or a
WebView. Its illustrative content cards and copy are not production authority.
Existing native content, routes, sessions, business rules, Chat and Back owners
remain authoritative.

Any later visual or interaction change requires a new immutable version and a
new founder acceptance cycle. This v1 directory must never be overwritten.
