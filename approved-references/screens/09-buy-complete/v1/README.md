# Screen 09 Buy module — founder FINAL HTML v1

This immutable reference freezes the complete founder-approved Buy HTML module
on 29 July 2026. It is the sole presentation authority for the first native
Flutter Buy V2 implementation.

The reference consolidates, and does not overwrite, the earlier immutable
catalogue and Cart slice checkpoints:

- `screens/09-buy-catalogue/v1`
- `screens/09-buy-cart/v1`

The complete scope includes Mool → Buy ownership; the always-visible Shop,
Wholesale, Medicine and Orders dock; context-specific search, filters and
category rails; Shop, Wholesale and Medicine product grids and product
decisions; prescription linking and pharmacist-review states; the compact
floating Cart; Shop, Wholesale, Medicine and ₹ Total Cart scopes; saved and
third-party delivery destinations; confirmation; active and delivered Orders;
tracking; reorder; Mool Assist; and documented recovery states.

## Permanent lock

Every file below this directory is immutable. No HTML, CSS, JavaScript,
reference image, evidence file, interaction contract, checksum or founder
acceptance record may be edited in place. A founder-authorized change requires
a new version directory and a new founder acceptance cycle.

The editable screenbook is no longer an authority for this accepted version.
Flutter must be implemented with native widgets in an isolated V2
presentation layer. HTML, a WebView, legacy Buy presentation, or a
functionally similar redesign cannot substitute for pixel, copy, motion,
navigation and interaction parity.

## Native acceptance boundary

Founder FINAL authorizes the native Flutter V2 implementation and its
verification work. It does not itself accept Flutter, authorize deployment,
or promote a build. Native acceptance still requires:

1. checksum and lock gates;
2. route-by-route native interaction tests;
3. matched HTML/Flutter viewport and text-scale comparisons;
4. complete affected tests plus two full regressions;
5. exact APK checksum verification on the connected OPPO;
6. clean, retained-data and interruption replay; and
7. founder acceptance of the installed candidate.
