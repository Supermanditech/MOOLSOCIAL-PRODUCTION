## Whirlpool interaction model

`Whirlpool` is the founder's engagement metaphor, not permission for a
disorienting spinning interface. The production model is a stable hub and
orbit:

1. **Mool is the centre.** Every primary surface reaches the exact MVP action
   hub in one deliberate tap.
2. **Chat is global.** Every primary surface reaches Chat in one deliberate tap
   and returns to the exact permitted origin.
3. **Forward motion has direction.** Entering a journey uses a compact
   container/shared-axis transition that makes the next depth unmistakable.
4. **Back restores context.** System Back, gesture Back and visible Back return
   to the prior exact state, selection and scroll position without rebuilding
   a generic root.
5. **Jumping remains simple.** Mool permits a one-tap jump to another main
   action; destination policy is checked before navigation and held/denied
   states never fall through to legacy UI.
6. **The customer stays oriented.** Stable headers, destination labels,
   selected action cues and predictable gesture ownership prevent the visual
   energy from becoming complexity.

## Native visual and motion standard

- Use the existing MoolSocial navy/saffron/green identity, ordered tricolour
  line and Apple-inspired product-design memory.
- Prefer compact decision surfaces, progressive disclosure and one obvious
  primary action over tall dashboards and repeated explanatory cards.
- Use restrained native Flutter motion: shared-axis or container transition,
  matched-element continuity, small spring/scale acknowledgement and clear
  forward/back direction. Avoid decorative perpetual loops, fake loading,
  uncontrolled rotation and motion that changes semantic ownership.
- Common transitions target roughly 180–320 ms, remain interruptible and
  restore state after app switching, lock/unlock and process recreation.
- Reduced motion removes non-essential translation, scale, blur and spring
  while keeping state change and navigation understandable.
- Meet the existing frame, accessibility, 44x44 target, text-scale, safe-area,
  keyboard/IME and semantic-focus gates on Android and iOS.
