# C14 ancillary contracts retained retired chooser roots

Date: 2026-08-08

Regression:
`REG-20260808-289-C14-ANCILLARY-CONTRACTS-RETAINED-RETIRED-CHOOSER-ROOTS`

## Failure

The named complete-universal failure set showed that C02, C10B, R03, R11,
R12 and Social-to-Work compatibility still treated retired Eat, Ride, Book
and Work chooser roots as canonical owners. Legacy recovery screens were
truthful, but their primary buttons still added an unnecessary compatibility
redirect before the supported owner.

## Root cause and prevention

The initial C13 migration covered the direct landing and vertical exposure
suites without inventorying every ancillary consumer of the old root routes.
Canonical Mool and Chat contracts now use exact default routes and owners;
hub, Chat and compatibility tests assert those real owners; and legacy
recovery buttons navigate directly to the appropriate supported surface.
Onboard and Verify recover to Workspace because their visible guidance names
Workspace, while Delivery recovers to Earn Today.
