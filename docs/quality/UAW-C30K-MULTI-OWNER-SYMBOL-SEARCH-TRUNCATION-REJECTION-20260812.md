# C30K multi-owner symbol-search truncation rejection

## Finding

A read-only symbol search combined the authenticated mobile gateway, large Flutter presentation owners and every social backend owner. High-frequency terms produced truncated output, so the result was not accepted as a complete reuse or authority audit.

## Disposition

Rejected and registered as `REG-20260812-1400-C30K-MULTI-OWNER-SYMBOL-SEARCH-TRUNCATION-REJECTION`.

## Permanent prevention

Audit each contract boundary separately with narrow symbols or explicit line ranges. Treat any truncated owner search as incomplete and never use it to authorize external writes.
