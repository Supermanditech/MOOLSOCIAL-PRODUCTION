# C33C Ride compact four-action destination-rail contract

Version: C33C / 15 August 2026

At widths where the existing local cluster fits, the shared destination rail
keeps its accepted compact-leading, non-scrollable geometry. When four local
actions cannot retain 44 logical pixels each after the global Mool, family
root and Chat controls reserve their widths, only the local cluster becomes a
bounded horizontal viewport.

The local actions retain their order, labels, selection semantics, indicators
and tap ownership. Mool, Ride home and Chat remain simultaneously present.
Normal motion and reduced motion both update Ride type in place without a
route replacement. No provider, map, live trip, payment, funds, screen, route,
state owner, service or backend owner is added.

The contract is source-qualified only. Checksum-matched OPPO acceptance and
any later release action remain separately gated.
