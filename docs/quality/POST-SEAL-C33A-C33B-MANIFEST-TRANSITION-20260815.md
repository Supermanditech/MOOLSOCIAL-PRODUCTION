evidence at SHA-256
`AF3C7B238428039F1F8904780E7B326EB6BCD8F46D62C461A5DB2950A198248A`.

The subsequent Ride source-audit wave must register new regression-memory
findings before any retry. Because the regression registry is a member of the
sealed manifest, the first such registration makes that manifest historical;
it must not be edited or described as the current source fingerprint.

A successor manifest may be created only after the bounded Ride wave has
completed, all changed and new evidence owners have been inventoried, and
every listed hash has been independently validated.
