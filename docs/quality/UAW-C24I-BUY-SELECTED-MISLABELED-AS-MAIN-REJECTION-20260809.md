# C24I Buy-selected evidence mislabel rejection

Date: 2026-08-09

The connected navigator began with Social selected. Tapping the verified Buy family node changed the overlay to the Buy-selected state and exposed Shop, Wholesale, Medicine and Orders. It did not yet navigate to Buy main, but the captured files were named `22-buy-main`.

Those files are preserved but rejected as accepted main-destination evidence. The corrected flow classifies and captures the Buy-selected overlay first, then uses a newly verified visible action for navigation.
