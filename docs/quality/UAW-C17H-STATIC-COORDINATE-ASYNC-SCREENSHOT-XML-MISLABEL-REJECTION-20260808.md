# C17H static-coordinate asynchronous screenshot/XML mislabel rejection

The initial C17H device-matrix batch used visually estimated coordinates and one timed delay. Two early screenshots showed a different selected route from the hierarchy captured immediately afterward, and subsequent taps crossed from subactions into main-family navigation. The files `01-social-shorts` through `04-social-create` are preserved but rejected as qualifying evidence; their filenames must not be treated as truthful state labels.

All replacement evidence uses semantic button bounds from the live hierarchy, waits for the expected `current` semantic in two consecutive dumps, and only then captures screenshot plus final XML. Replacement files use unique `q` prefixes and never overwrite the rejected batch.
