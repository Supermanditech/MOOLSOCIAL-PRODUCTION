# C22G capsule-system host qualification preselection — 2026-08-08

C22G is test/gate-only. Runtime, backend, build, install and device writes are closed. It reuses the existing Flutter suites and protected gates, adds one machine-readable C22 contract plus a positive/negative mutation gate, and runs two consecutive complete cycles over an unchanged SHA-256 source fingerprint.

The required suite covers fixed 72×48 capsules, six family palettes, raw-pixel zero strap, 2/3/4-action reverse-U geometry, all 17 local taps, disclosure/reduced motion, selected semantics, main/subaction parity, route projection and protected application regressions. Installed founder-rejected r60.20 checksum identity must remain preserved throughout.
