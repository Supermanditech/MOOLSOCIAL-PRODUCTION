# C25F C13 direct-default contract rejection

Date: 2026-08-09

## Observed rejection

The C13 suite produced eleven failures because it still required a second
subaction tap on Home, the removed large destination launcher and no local
rail. Its Shop route expectation also omitted the explicit `?sub=shop` default
now used by the shared projection.

## Corrective boundary

Preserve the six exact default destination owners and the four legacy-root
redirect guarantees. Each Home family must open its default owner in one tap,
and the destination must expose the compact launcher and its own local family
rail. Only obsolete presentation steps and Shop's explicit route expectation
may change.

No new routes, features, build or install authority are opened.
