correction already requested by the founder. It adds no customer scope.

in-place install only after checksum, v2 signature, version, package, source

and Android client configuration only inside its process memory. Codex will
not request, inspect, copy, print, hash or persist those values. No cloud write,
deploy or capability expansion is authorized.
