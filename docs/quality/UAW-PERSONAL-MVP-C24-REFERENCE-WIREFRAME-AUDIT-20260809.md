# C24 founder reference and production-owner audit — 2026-08-09

## Reference boundary

Nine founder-supplied files were visually inspected in place and checksum-pinned in `config/mvp-reference-service-home-contract-c24.json`. They are directional wireframe evidence only. No file is copied into the production repository, no external brand is used in production copy, and no reference becomes a route or implementation owner.

## Reusable information hierarchy

- Doctor: search first; upcoming appointment; specialty categories; top-provider trust facts; direct booking; later appointment, chat/video and follow-up continuity.
- Ride: current pickup; a dominant destination prompt; recent and saved places; vehicle, fare and arrival choices before confirmation.
- Bus: From, To and Date in one bounded decision card; swap; Today/Tomorrow; one search action; operator, departure, arrival, duration, seats, rating and fare in results.
- Eat: location and search; compact food categories/filters; restaurant/menu cards with rating, time, distance, availability and price; direct Order Food or Book Table action.

Promotional clutter, copied logos, bottom navigation, advertising, decorative map imagery, excessive gradients and obstructive overlays are rejected. Work receives the same shared hierarchy using only its existing truthful opportunity/workspace data; no reference-only Work features are invented.

- Eat already owns Order Food and Book Table routes, screens, session, models, services and vertical-slice tests.
- Ride already owns one parameterized booking route for Bike, Auto and Cab, one booking screen, session, models, services and tests.

Therefore C24 reuses every current domain and route owner except the founder-required Bus leaf. Bus receives one new screen and one route under the existing Book domain; no backend owner is added.

## Visual and interaction outcome

Changed homes use one shared 16-pixel page grid, 24-pixel section rhythm, 18-pixel card radius, 52-pixel search field, 48-pixel primary action, minimum 44-pixel tap target and a 28/20/16/14/12 type scale. A quiet light foundation and one restrained family accent keep content legible. Every first viewport answers where the user is, what they can search or choose, what it costs or when it arrives, and the next direct action.

Mool and Chat continuity, Back behavior, finite motion, immediate reduced motion, 320–430 pixel adaptation and 1.4 text scaling remain release gates.
