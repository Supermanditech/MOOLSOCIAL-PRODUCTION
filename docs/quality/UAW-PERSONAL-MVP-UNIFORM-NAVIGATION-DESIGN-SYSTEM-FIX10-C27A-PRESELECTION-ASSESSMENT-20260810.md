Classification: `mvp_required`.

Customer outcome: one evidence-backed standard governs the accepted embedded
Mool switcher and every Social, Shop, Food, Travel, Care and Work bottom action
rail before shared Flutter mutation.

## Reuse and duplicate search

- Reuse `MoolDestinationNavigationV2`, `MoolGlobalNavigationV2`,
  `MoolConnectedActionNavigator`, `MoolLocalNavigationRail` and
  `MoolLocalNavigationTokens`.
- Reuse all existing family action catalogues, routes, semantics and feature
  state owners.
- The bounded duplicate search found all six founder-facing projections already
  converge on the same two shared presentation files.
- Create no screen, route, backend, session, controller or feature-local rail.
- Add one successor design contract and focused machine gate because current
  C26 tests do not assert uniform typography, background, selected hierarchy,
  sparse alignment or Android-exported accessibility bounds.

## Robustness and delivery fit

The adjustment is central shared-owner reuse, not feature duplication. It
retains reduced motion, Back/outside/swipe dismissal, one-tap direct actions,
all protected content owners, and the installed C26H predecessor until a later
host-qualified build ticket opens. Estimated impact is three days and remains
inside the founder's 60–75-day lock.
