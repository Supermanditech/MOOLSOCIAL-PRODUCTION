# C17G optional battery-policy ripgrep no-match rejection

The follow-up battery diagnostic successfully read the live OPPO state, then an optional regression-registry `rg` query found no matching battery policy and returned exit 1. Because the two reads were aggregated, the tool call appeared failed even though the authoritative device output was valid.

Optional no-match searches are now separated or normalized. They cannot invalidate live device evidence or trigger install. No device mutation occurred.
