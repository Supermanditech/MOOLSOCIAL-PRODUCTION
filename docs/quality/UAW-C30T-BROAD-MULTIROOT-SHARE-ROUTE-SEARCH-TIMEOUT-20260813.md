# C30T broad multiroot share-route search timeout

Date: 2026-08-13

One broad public-share route search included application, backend, deployment, documentation and configuration roots. It exceeded the ten-second command budget, which invalidated the combined parallel diagnostic even though partial text was emitted.

The retry must use bounded current source roots, exclude generated backend output, and assess each search independently. No product, backend, provider, device, AAB, Play or communication state changed.
