# C24B1 founder OPPO Home/navigation contract preselection

C24B1 is the smallest response to the founder's new installed-device rejection: register and freeze the exact Home, connected navigation and brand-space outcome before changing the runtime again.

The ticket reuses the current `PersonalMoolRootV2`, `MoolDestinationNavigationV2`, `MoolGlobalNavigationV2`, six-family action catalogue, route callbacks and Back/Chat state. It creates no screen, route, backend owner, persistent business state or subaction. It separates the implementation into C24B2 fixed-viewport Home and C24B3 connected destination navigator so each acceptance unit can gate the next.

The professional target is not an Apple trade-dress copy. It adopts platform-level restraint: one fixed viewport, strong alignment, quiet neutral surfaces, six main-family choices, only the selected family's actions, one consistent MoolSocial launcher and no redundant welcome/brand chrome.

C24B1 authorizes repository contract/ticket/test-gate state only. Runtime, backend, build, install, device, external service, credentials, messages/calls, funds and Production remain closed.
