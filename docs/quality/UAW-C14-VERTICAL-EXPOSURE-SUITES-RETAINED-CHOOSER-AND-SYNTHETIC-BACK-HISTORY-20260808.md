# C14 vertical exposure suites retained chooser and synthetic Back history

Date: 2026-08-08

Regression:
`REG-20260808-286-C14-VERTICAL-EXPOSURE-SUITES-RETAINED-CHOOSER-AND-SYNTHETIC-BACK-HISTORY`

## Failure

The complete universal cycle and independent R06 run exposed production-route
tests that still expected `mvp-action-root-eat` after `/app/eat`, after direct
Eat sub-action Back, or before falling to Personal Mool. The equivalent Ride,
Book and Work exposure owners are part of the same inherited chooser contract.

## Prevention

Each supported main-action route resolves directly to its default destination
and family strip. A non-default local choice may push and Back to the default;
the root itself never creates chooser history. Top-level screens have no
header Back and Mool is reached only through its explicit stable global action,
which then returns to the exact prior destination. Direct deep-link tests prove
the real owner and global rail without inventing an intermediate route.

Component-only chooser harnesses remain explicit legacy-test coverage and do
not qualify production navigation.
