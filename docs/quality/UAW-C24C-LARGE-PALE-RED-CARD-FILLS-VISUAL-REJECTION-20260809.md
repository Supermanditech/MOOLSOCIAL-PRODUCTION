# C24C large pale-red card fills visual rejection — 2026-08-09

The first 360 × 800 OPPO-class Eat render showed the Book Table card and the
session's default restaurant as large pale-red surfaces. Although legible, the
combined fill competed with the white discovery hierarchy and repeated the
founder's earlier concern about theme colour blocking the background.

REG640 makes Eat discovery cards white and keeps the restrained family accent
on icons, arrows, filter outlines and the explicit table-selection check. The
successor golden replaces this rejected visual in the same evidence path only
because C24C is not yet qualified or accepted.
