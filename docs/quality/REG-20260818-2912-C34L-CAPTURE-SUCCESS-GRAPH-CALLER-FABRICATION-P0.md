# REG2912 — C34L capture success graph caller-fabrication P0

## Finding

The independent C34L PRE-AAB FIX2 audit confirmed that capture contract v2 binds role, path, SHA-256, bytes and media type, but no production capture producer authenticates the observations. Play, OPPO and journey final writers accept caller success switches/counts while manifests self-declare producer, session, nonce, timestamps and artifacts.

An actor able to create the expected immutable JSON files can therefore construct a fully hash-consistent success graph without real Play, OPPO or journey observations.

## Impact

- PRE-AAB-2 FIX2 is rejected at P0 despite dual-host fixture success.
- C34L must not seal source, run cycles, expose the founder launcher, build, upload, update OPPO or begin private journeys.
- No real action occurred while discovering or registering this finding.

## Required repair

- Production writers expose no caller success booleans/counts or self-declared producer/session/artifact claims.
- An immutable transition journal issues a single-use candidate/evidence-type/session/challenge bound to the source seal and exact producer script hash.
- Source-specific Play, OPPO and journey producers own raw observations and derive all results.
- Manifest and attestation bind producer path/SHA/bytes, source seal path/SHA/bytes, raw source receipt path/SHA/bytes/media type, challenge/session, preimages, vector and transaction journal.
- Boolean/manual adapters exist only inside exact checker-owned fixture roots and are rejected in production.
- Dual-host fixtures reject forged JSON, wrong producer/source seal, replay, tamper, reparse and fixture escape with zero real/external actions.
