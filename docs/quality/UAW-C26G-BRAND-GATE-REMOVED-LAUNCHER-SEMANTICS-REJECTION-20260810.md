# C26G brand gate removed-launcher-semantics rejection

The second C26G preflight passed the aggregate, C26B through C26F, C25A, placement and approved-reference gates, then rejected because the brand gate still required the removed `Open MoolSocial actions` semantics label.

The current approved accessible name is `Open MoolSocial main menu`, matching a switcher that exposes only Social, Shop, Food, Travel, Care and Work. The permanent brand gate is migrated to that literal; focused C26C coverage retains the six-family interaction contract.
