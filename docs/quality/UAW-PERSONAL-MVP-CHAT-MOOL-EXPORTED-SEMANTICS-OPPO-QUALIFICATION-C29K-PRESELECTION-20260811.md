# C29K OPPO successor preselection

C29K is the separately registered physical-device successor to source-qualified C29J. It reuses the existing one-build wrapper, APK regression gate, YouTubePublicDevReview runtime profile, Firebase Android client metadata, Play Integrity App Check registration and the 23-owner C29J source manifest.

The customer outcome is bounded: install one checksum-qualified r60.34 in place on OPPO serial `2b3e0f71`, prove the shared Chat Mool target exports at least 44 logical pixels, and replay Home, Shorts, vertical next-Short, video watch, Create, Feed, Chat and Mool without internal customer commentary. No new product surface, backend owner, provider capability, credential persistence or upload/OAuth claim is introduced.

The candidate permits one profile build only after two fresh selected-candidate source cycles and the exact same-shell no-token gcloud, process, source and installed-r60.33 gates pass. Installation opens only after checksum, size, package/version, v2 signature, signing certificate and provenance qualification. It permits one `adb install -r` only; uninstall, data clear, downgrade, second build, second install and protected-baseline update remain forbidden.
