# C17H founder-gallery inventory host-expansion rejection

Date: 2026-08-08

The first read-only gallery inventory did not enumerate any file. PowerShell expanded the Android shell loop variable inside a double-quoted adb argument before the command reached the device, producing four empty directory tests. No device file was read, copied, moved, deleted or modified.

The retry contract is to use literal device roots or an Android-shell expression protected from host expansion.
