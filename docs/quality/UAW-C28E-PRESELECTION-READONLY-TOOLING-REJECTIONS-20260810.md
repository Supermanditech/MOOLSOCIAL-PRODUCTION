# C28E preselection read-only tooling rejections

Neither rejection mutated runtime, APK, installed app or device state.

1. The required full dirty-tree inventory used `git status
   --short --untracked-files=all` without suppressing known Windows long-path
   warnings. Counts completed, but warning output exceeded the bounded evidence
   channel and was truncated.
2. An optional protected-owner lookup used two raw `rg` commands whose valid
   no-match exit code 1 was surfaced as a failed shell script, recurring the
   already registered optional-search class.
3. The first C28E machine-scope transition used one oversized copied JSON
   patch. An expected FSC06 context block did not match the live file exactly,
   so `apply_patch` rejected the entire transition before mutation.
4. The first focused C28E test run found that the shared rail and its widget
   test referenced `defaultTargetPlatform` and
   `debugDefaultTargetPlatformOverride` without importing
   `package:flutter/foundation.dart`. The two independent system-mode tests
   passed; the widget test failed to compile and no runtime evidence was
   claimed.
5. The next focused run proved that `Scaffold` removes the top
   `MediaQuery.viewPadding` from the bottom-navigation subtree. The first
   clearance implementation therefore received zero instead of the raw 41
   logical OPPO top inset, leaving the predecessor 102-pixel shell unchanged.
6. The non-Android widget case changed
   `debugDefaultTargetPlatformOverride` inside the test and relied on teardown
   to restore it. Flutter verifies foundation globals before that teardown, so
   the invariant correctly rejected the leaked override.
7. The first corrective patch for items 5 and 6 again grouped registry,
   evidence, runtime and test changes. Dart formatting had changed one expected
   test context, so the entire oversized patch was rejected before mutation.
8. After switching to raw view insets, the Android platform variant supplied a
   conservative 31-pixel clearance instead of the nominal 27-pixel OPPO
   example. The test incorrectly pinned the total shell to 129 and rail bottom
   to 735 even though the actual 133/731 geometry improves exported height.
9. Readback then proved the four-pixel difference came from using
   `MoolMetrics.compactTapTarget` (48) instead of the contract's
   `MoolMetrics.minimumTapTarget` (44). The implementation was conservative but
   exceeded the founder-disclosed smallest scope.
10. The first complete C28E gate preflight stopped at the live C27D static gate,
    which still required Buy local `shop`/Products after founder-authorized
    FSC06 removed that duplicate. Earlier focused FSC06 tests passed, but this
    predecessor source gate had not been migrated.
11. The restarted preflight advanced to C26D, whose Buy projection still
    required `label: 'Products'` and reported three Shop actions. It was the

12. The first complete C28E qualification cycle reached full Flutter analysis,

Prevention: capture Git stderr separately and output only counts for large
inherited trees; use `Select-String` or explicitly accept ripgrep exit code 1
for optional discovery. No retry is required because subsequent owner
resolution used bounded `Select-String` evidence.
Scope transitions must use small exact live sections; never make activation
depend on one copied multi-section JSON hunk.
Every Dart owner that directly uses platform globals must import
`flutter/foundation.dart`; do not rely on Material exports.
Window-level inset policy must read `View.of(context).viewPadding` and convert
physical pixels using the view DPR; a Scaffold-mutated subtree MediaQuery is
not the window owner. Widget tests must use `TargetPlatformVariant`, which
restores platform state before framework invariant checks. Apply each
corrective file independently against current formatted text.
Viewport tests assert the customer contract—exported height at least 44,
unchanged 58-pixel cells and a rail no lower than the accepted reach bound—not
an exact clearance total that may vary with the test view's platform metrics.
The exported minimum formula must use `minimumTapTarget`; `compactTapTarget`
is a separate 48-pixel component token.
Every successor host preflight must run the full historical gate inventory;
when a founder-authorized catalogue correction invalidates a static predecessor
literal, migrate the live gate to assert both the new projection and explicit
absence of the removed member.
The same migration applies to C26D: require Wholesale and Orders, require the
retained shared Shop family root through focused proof, and reject Products and
the removed local Shop tab.
Every host-qualification cycle must treat analyzer info diagnostics as a hard
gate. Import platform symbols from the narrowest library that actually owns
them, but remove a direct foundation import when Material already provides all
symbols used by that test. After any cycle-source correction, start from a new
evidence-directory identity and require both unchanged-fingerprint cycles
again.
Run repository gates from the repository root and invoke Flutter through the
mobile working directory only in a separate command. Never combine commands
whose relative path owners have different roots.
PowerShell readbacks use ticket-specific names such as
`$c28eHostQualificationContract`; never assign to automatic-variable aliases
including `$Host`, `$host`, `$HOME` or `$home`.
When a complete suite fails and the bounded output omits the failure blocks,
register the suite failure before rerun. Re-execute the unchanged catalogue
with a structured reporter or in bounded partitions to identify the exact
owners; do not guess, suppress tests or accept the cycle from summary counts.
Required connected-navigation journeys use a retained customer action after
FSC06. Exercise `Wholesale` through `buy-local-tab-wholesale` while preserving
the shared Shop family root; never recreate the removed local Shop cell to make
a historical test pass.
Never overwrite or weaken a protected Social baseline after an authorized test
migration. Audit the active ticket's exact test-owner authority and the
successor-seal protocol; if authorized, create a new immutable candidate seal
and point only the successor host contract at it. Otherwise stop at the gate.
List an evidence directory before reading children and treat its actual
inventory as authoritative. Do not infer a manifest file from a historical
field that points to a different predecessor directory.
Resolve delivery-lock owners from the live scope contract and verify the exact
referenced path before reading it. Do not derive a shorter filename from a gate
or field label.
Read optional XML attributes with `GetAttribute`; an absent
`visible-to-user` value is eligible, while the exact value `false` is excluded.
Self-tests must reach both positive and negative geometry assertions before the
gate is accepted.
Apply the attribute rule to the entire XML gate in one audited pass, including
`content-desc`, `text`, `bounds` and package visibility reads; do not correct
only the first reported attribute.
Optional JSON contract fields also require an explicit property-presence check
under strict mode. Resolve absent family forbidden-label lists to an empty
array; do not require irrelevant families to duplicate Buy-only policy.
Resolve preserved device fixtures from a bounded directory listing and hash the
exact retained child before sealing a successor contract. Human evidence prose
does not replace filesystem identity proof.
Device identity probes must return explicit bounded `key=value` scalars in the
tool result. If a yielded compound command loses its output, register it and
rerun small independent read-only probes; never infer identity from exit zero.
Coerce native single-line Git identity output to `[string]` before trimming and
do not index it. Any PowerShell error invalidates every scalar from the compound
audit; rerun the complete bounded Git projection.
Evidence patches use an immediate literal tail read and file-local exact
context. A rejected combined patch is no mutation and is registered before a
smaller retry.
Before a successor machine-state transition, the negative APK gate may reject
at candidate identity, machine state or one-build authority. The self-test
matches the exact current earliest closed boundary and still forbids a pass.
Machine-state readback verifies one bounded nested section at a time and emits
only named scalars; a truncated compound projection proves none of its fields.
Optional fixed-string discovery explicitly translates ripgrep exit code 1 to
zero matches before continuing; it is never grouped as a required lookup.
Resolve the active scope-state path from a bounded `config/*scope*` inventory
or an already proven contract reference before reading it; never reconstruct
the filename from the logical owner name.
Read the registry root property inventory before counting, and count the exact
`entries` array; a missing property is a projection error, not a one-entry
registry.
Compute and compare the live registry count and manifest line only after every
required failure entry is persisted; never increment a source-manifest count
from an assumed prior total.
Discover scope validators from a bounded `scripts/*scope*` inventory and invoke
only a proven filename; a logical contract name does not prove a script path.
Every newly added registry gate path is existence-checked against the bounded
live inventory before the regression-memory gate retry; failure records never
repeat an unproven filename as their own prevention gate.
Assign each `Test-Path` result to a named boolean before combining conditions;
never place Boolean `-or` between unparenthesized cmdlet invocations. Any
PowerShell error invalidates earlier scalars from the compound audit.
For postbuild Android metadata validation, first prove the short generated APK
and immutable evidence APK have identical SHA-256 and byte length, then pass
the absolute short generated path to `aapt`; check its exit code immediately.
Do not rebuild or relocate the evidence artifact to bypass a validator limit.
Nested machine-state patches include their unique parent-object context and an
immediate line-bounded readback; never patch a repeated field name such as
`evidence` without proving which object owns it.
The mandatory literal Git status command may be run for compliance, but durable
reconciliation evidence records only branch, HEAD, staged/tracked/untracked
counts and path-safe digests; never render the inherited path list again.
Gradle's stop acknowledgement is not process-exit evidence. Require the exact
PID to disappear; when the founder has explicitly authorized all required
toolchain cleanup, terminate only that proven daemon PID and immediately rerun
the global Flutter/Dart/Gradle/Java zero-process audit.
An exact cleanup target that is already absent is a safe no-op, not a failure.
Record `already_absent`, perform no termination, and let the subsequent global
zero-process audit—not the cleanup wrapper—decide install readiness.
Before consuming an ADB install command, prove the immutable evidence APK and
short generated APK are checksum/byte identical, then pass the absolute short
generated path to Windows `adb`. A host-side stat rejection consumes its
command authority, keeps device install count zero, and requires separately
sealed founder-authorized recovery plus a fresh full preinstall audit.
Family-switcher selection establishes the shared family home only. When the
matrix plans a local action rather than the family root, capture the
intermediate home only as diagnostic evidence, then invoke the exact local
semantic and capture its selected state; never infer first-local selection.
Exact device semantics are read from the freshly retained pre-tap hierarchy.
Do not synthesize `Open <label>` from the contract label; if the planned local
is already current, capture it directly, otherwise invoke only the hierarchy's
proven exact clickable semantic.
Every switcher dismissal state requires the closed Mool semantic and explicit
absence of `MoolSocial main actions`/`Close MoolSocial main menu`, in addition
to destination continuity. A visible destination behind an overlay is not
proof that swipe-down, Back or outside dismissal succeeded.
Ticket closure changes the scope contract's top-level lifecycle state and
checkpoint together with execution booleans. Read the live scope gate's exact
closed/founder-review branch before patching; zero authorities alone do not
constitute a valid closure.
Apply scope lifecycle corrections as separate small hunks against immediate
literal live lines, with a bounded readback after each group. Never make an
otherwise valid top-level closure depend on remembered checkpoint prose.
Final handoff does not enumerate the inherited untracked tree. Report it as
retained and unbounded; collect branch/HEAD, tracked dirty count and staged
count in independent warning-suppressed commands, and never claim an
untracked count from a warning-producing inventory.
For bounded multi-file metadata inventory, assign `foreach` output to a named
array and format that collection only after enumeration completes. A parser
rejection proves no file inventory and must not be treated as partial output.
Regression-memory invocations use only the script's proven `Phase` ValidateSet;
host-only successor planning uses `general` with build mode `none`.
