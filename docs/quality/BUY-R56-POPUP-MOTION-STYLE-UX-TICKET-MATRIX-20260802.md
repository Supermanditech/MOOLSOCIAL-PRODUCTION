## Shared popup directive

Every family must preserve its real session owner and use the same product
language:

- finite, bounded native arrival and matching reverse; the existing 280 ms
  route/220 ms recovery policy is the default starting point, subject to the
  family audit;
- zero-duration, static reduced motion with no delayed substitute;
- stable compact geometry, SafeArea, drag handle where dismissal is safe,
  deterministic scrim/Back/focus/keyboard/lifecycle/process behavior and a
  complete semantics route;
- white surface, navy hierarchy/actions, Indian saffron only for purposeful
  attention/focus, and Indian green only for a real positive owner change;
  promo-aperture contextual colour must not leak into shared tokens;
- clear rounded grouping, persistent field labels, visible cancel/confirm
  hierarchy, disabled duplicate submission only during a real asynchronous
  operation, and no clipped actions at 320 px/140% text; and
- animate empty/success/error/warning content only when the real owner changes.
  Never invent a wait, result, approval, validation, payment, completion,
  recovery, offer, live state, entitlement or provider fact.

Every candidate requires focused normal/reduced/responsive tests, Android/iOS
captures, two unchanged-source full Buy regressions, every mandatory gate,
machine-gated profile build, checksum-matched OPPO replay, accessibility tree,
keyboard/focus/Back/lifecycle/process recreation, failure scan, performance
trace and exact source manifests.
