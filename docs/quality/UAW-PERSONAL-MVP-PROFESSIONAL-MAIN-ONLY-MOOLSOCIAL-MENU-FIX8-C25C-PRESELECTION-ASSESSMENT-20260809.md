# C25C preselection assessment

C25C reuses the current MoolSocial Home route, connected dialog, shared catalogue, motion tokens and glass primitives. The current production composition is rejected because it requires family selection and then renders direct subactions inside the same popup. The smallest complete correction is to compose the same six catalogue families as direct default-destination controls and remove the selected-family action region from both Home and the destination dialog.

No new screen, route, backend, service or persistent state is necessary. Focused tests cover six main actions only, one-tap default routing, 44 px controls, finite 180–220 ms motion, immediate reduced motion and absence of subaction controls. Build/install/external authority remains closed. Timeline impact is one day within the delivery lock.
