# C29P large shared-model unbounded read repeat rejection

## Rejection

The 1,818-line shared model owner was requested as one complete read during the
C29P reuse audit. The output truncated, repeating the permanent large-owner
context failure. No truncated content was admitted as evidence.

## Permanent prevention

Line-count every owner before a full read. Read large owners only through
explicit non-overlapping ranges and resolve the narrow declaration region first.
