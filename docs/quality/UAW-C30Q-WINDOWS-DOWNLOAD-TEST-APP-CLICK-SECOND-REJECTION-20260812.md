# C30Q Windows Download test app click second rejection

Date: 2026-08-12

## Mistake

After permanent registration and a fresh window observation, the one permitted recovery click on `Download test app` again failed at the Windows-control input layer. A new observation proved that the page still had not navigated.

## Impact

- No download or installation started.
- The Supermandi tester enrolment remained valid.
- No Play, repository machine state, device, account, credential, or application data changed.

## Permanent prevention

Do not automate this link again through Windows control. Hand this single visible link click to the founder, then resume from the resulting Google Play listing with a new observation. Installation itself remains separately gated and Play-mediated.
