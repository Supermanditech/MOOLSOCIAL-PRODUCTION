# C30T YouTube pre-consent user-controls finding

Date: 2026-08-13

The optional read-only connection screen exposed privacy, deletion, revocation help and Google permissions only after a channel was connected. An unconnected user therefore had to begin Google consent before seeing MoolSocial's complete user-control surface.

The same controls are now visible before connection with copy explicitly stating that connection is optional, read-only and cannot perform YouTube mutations. A focused test proves privacy, Google permissions and deletion open without starting the connection. Connected-state controls remain unchanged in function. No OAuth, provider, release or external state changes.
