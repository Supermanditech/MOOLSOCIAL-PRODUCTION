# C21D preselection robustness and reuse assessment — 2026-08-08

C21D is MVP-required configuration/focused-test work for the actual Shop, Wholesale, Medicine and Orders outcomes. It reuses `BuyV2Session`, `_buildBuyLocalNavigation`, `MoolLocalNavigationRail` and the completed C21B light-tone lens. No new widget owner, screen, route, catalogue, backend, persistent state or sub-action is necessary.

Minimum scope is a compact four-action cluster with a controlled near-white neutral gradient across every Buy destination, stable identity-navy labels/icons, visible gaps, no peach/green/teal colour flooding, and product/catalogue content remaining dominant and reachable. Selected/inert, available/one-tap, text-scale, motion and reduced-motion behavior remain shared. Routes, vocabulary, provider/business rules and the contextual header are protected.

Implementation disposition is configuration plus test-only acceptance, with a one-day-or-less delivery impact and no topology growth. C21A–C, the C21 shared/placement/Social gates, protected UI/brand/copy/interaction gates, permanent memory and installed r60.19 identity are dependencies. Build/install, screenbook, backend/provider/business, credentials, messages/calls, funds, Production, commit/push/deploy/promotion remain excluded.
