# C24C Book Table metadata overflow visual rejection — 2026-08-09

The retained first Book Table capture exposed a vertical RenderFlex overflow
stripe through the selected restaurant card. The sentence-length availability
copy was placed in a compact metadata row beside the selection icon.

REG642 moves availability into the wrapping subtitle and reserves metadata for
short rating, distance and price values. The successor capture must show no
overflow marker at the OPPO-class viewport.
