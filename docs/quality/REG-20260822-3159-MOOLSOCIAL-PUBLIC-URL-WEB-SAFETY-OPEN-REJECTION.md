# REG3159 - MoolSocial public URL web-safety open rejection

## Classification

Registered batched read-only external-open rejection with zero external mutation.

## Evidence

The web opener rejected direct opens for the public YouTube API, privacy, terms, disconnect and delete-account URLs as unsafe in that tool context. No page result was inferred and no site, account or external service was changed.

## Prevention

Do not retry that web-open route. Use one bounded unauthenticated public HTTP status/title readback after registration; keep every login and external write prohibited.
