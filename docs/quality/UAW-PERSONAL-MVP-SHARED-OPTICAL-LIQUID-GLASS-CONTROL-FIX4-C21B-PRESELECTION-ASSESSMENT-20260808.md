# C21B preselection robustness and reuse assessment — 2026-08-08

## Scope and founder disclosure

C21B is MVP-required runtime and focused-test work. It changes only the existing shared native Flutter sub-action tokens/control so all six families receive a device-visible independent optical-glass language. The founder was shown the exact r60.19 failures and the expected neutral-lens, real-blur, specular-edge, single-selection target before execution.

## Reuse and duplicate decision

Search found `MoolGlassSurface`, `MoolLocalNavigationTokens`, `MoolLocalNavigationRail` and `_MoolLocalNavigationCell` in `mool_design_system.dart`, plus the existing destination wrapper in `mool_global_navigation_v2.dart`. C21B evolves these owners and their existing tests. No screen, route, backend owner, persistent state owner or sub-action is added. Implementation disposition is reuse plus configuration.

## Minimum complete scope

- Independent 44–48 px neutral lenses with visible gaps; no family band or segmented strip.
- Controlled light/media luminance, real backdrop blur, restrained shadow and specular top/inner edge.
- One selected grammar: brighter/elevated lens plus one micro-indicator, without a heavy selected outline.
- Standardized 20 px optical icon box and 13 px/700 label treatment through 130% text scaling.
- 80–120 ms press response, 160 ms state response and immediate reduced motion.
- Focused widget/token tests and existing C16/C20 regression gates; build and install remain closed.

## Dependencies, robustness and exclusions

C21A is complete. The existing rail geometry/order/position/meaning, one-tap routes, disclosure, Back, Mool, Chat, copy, provider/business logic and content are protected. The change remains within the 60–75 day lock with an estimated one-day impact and no implementation-topology growth. Screenbook mutation/copy, backend/provider/business mutation, APK build/install, uninstall/data clear/downgrade, credentials, messages/calls, funds, Production, commit/push/deploy/promotion remain excluded.
