# Screen 04 production-copy machine gate

Every visible or semantic string owned by native Flutter V2 Screen 04 must be
written for the customer who is using the released app.

The gate fails when Screen 04 exposes any of the following:

- example, sample, demo, mock or placeholder wording;
- founder-review, test, prototype, implementation or developer commentary;
- internal plans, working notes, state names, payloads, endpoints or backend
  terminology;
- generic completion text that does not name the action or result;
- an action label that describes the implementation instead of what the
  customer can do.

The gate covers visible text, sheets, validation and recovery copy, semantics,
tooltips and route-owned Screen 04 states. It must run with the responsive
matrix and the connected-device replay. Screens 01–03 remain read-only.
